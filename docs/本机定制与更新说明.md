## 更新流程

### 方式一：面板「立即更新」（推荐）

已设置用户环境变量：

```
WECHAT_UPDATE_REPO = whallx1/wechat-bot
```

面板 →「更新」→「检查更新 / 立即更新」拉的是自己的 fork，改动不会丢。
（该变量对**已运行**的 DSH 不生效，重启 DSH 后读取。）

### 方式二：命令行合并上游

```powershell
$git = 'D:\ai\WorkBuddy\resources\vendor\PortableGit\cmd\git.exe'
cd D:\ai\wx\wechat-bot-main
& $git fetch upstream main
& $git merge upstream/main     # 冲突就手动解决后 commit
& $git push origin main        # 推到自己的 fork
```

## 注意

- PortableGit 不在系统 PATH：`D:\ai\WorkBuddy\resources\vendor\PortableGit\cmd`
- 以下内容不会入库（已在 `.gitignore`）：`data/`、`*.db`、`backups/`、`node_modules/`、`config.json`、`*.log`
- 本机补丁整包备份：`backups/local-patches-2026-10-31/`（含 `restore-local-patches.ps1`）
